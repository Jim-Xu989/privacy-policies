隐私政策（Privacy Policy）

生效日期 / Effective date: 2026-10-29

本隐私政策说明「代理切换器」（Proxy Switcher，以下简称“本扩展”）如何处理用户数据。本扩展由个人开发者独立发布，不隶属任何公司。

1. 我们收集的数据

本扩展不收集、不传输、不上传任何个人数据或可识别信息。

2. 数据存储位置

你配置的代理服务器、规则与偏好全部仅保存在你本机浏览器中（通过 Chrome / Edge 的 chrome.storage.local 本地存储）。这些数据不会离开你的设备，也不会发送到任何远程服务器。

3. 代理凭据

如果你在配置中填写了代理的用户名与密码，这些凭据仅存储于本地，并仅用于向你所配置的代理服务器发起连接。我们不会读取、收集或外传这些凭据。

4. 遥测与分析

本扩展不包含任何遥测、统计分析或第三方跟踪代码。

5. 远程代码

本扩展不包含任何从远程服务器加载的可执行代码；全部逻辑均随扩展包在本地运行。

6. 网络访问说明

本扩展通过浏览器代理机制为你的请求应用路由规则。清单中声明的 host_permissions: <all_urls> 仅用于让代理规则能够覆盖你访问的站点，所有路由决策在本地完成，不会将你的浏览内容发送给我们。

Privacy Policy

Effective date: 2026-10-29

This privacy policy explains how “Proxy Switcher” (the “Extension”) handles user data. The Extension is published by an individual developer and is not affiliated with any company.

1. Data we collect

The Extension does not collect, transmit, or upload any personal or identifiable information.

2. Where data is stored

Your proxy servers, rules, and preferences are stored only in your local browser using chrome.storage.local. This data never leaves your device and is never sent to any remote server.

3. Proxy credentials

If you enter a username and password for a proxy, those credentials are stored locally only and are used solely to connect to the proxy server you configured. We do not read, collect, or share them.

4. Telemetry and analytics

The Extension contains no telemetry, analytics, or third-party tracking code.

5. Remote code

The Extension contains no executable code loaded from remote servers. All logic runs locally from the extension package.

6. Network access

The Extension applies routing rules to your requests through the browser’s proxy mechanism. The host_permissions: <all_urls> declared in the manifest is used only so that proxy rules can cover the sites you visit. All routing decisions are made locally; your browsing content is never sent to us.
